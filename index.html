01. Sobre mí

Soy un desarrollador Front-End enfocado en construir experiencias web memorables. Mi formación en Informática y Ciberseguridad me da una ventaja única: no solo creo interfaces atractivas, sino que también me preocupo por escribir código seguro y accesible.

He llevado proyectos reales a producción, destacando NOIR Shop (un e-commerce completo con carrito funcional y filtros dinámicos) y BlogDeCafé (una arquitectura semántica optimizada para lectura). Disfruto resolver problemas de UI y optimizar el rendimiento.

Mi stack de desarrollo:

  • HTML5 & CSS3
  • JavaScript ES6+
  • Flexbox / CSS Grid
  • Diseño 100% Responsive
  • Git & GitHub
  • Deploy (Netlify/Vercel)
